    复习记忆目标

    FSRS 根据作答调整每个词的复习间隔。目标越高，复习越频繁；建议先使用 90%。修改后从下一次作答生效。

    发音

    认词时朗读；拼写题作答后朗读，避免提前透露答案（使用系统语音）。

    进度数据

    学习进度保存在本机浏览器。升级前会自动备份旧进度；可导出备份留存。换设备或换浏览器时，用导出/导入搬运。

    多设备同步

    进度存进一个私有 GitHub 仓库，手机和电脑打开就自动合并。 两台设备各练各的词不会互相覆盖 —— 按每个词「最后练习时间」取新的那条，对错次数取较大值。

    也可以直接粘贴整个仓库网址，会自动拆成所有者 + 仓库名。

    只存在这台设备的浏览器里，只会发往 api.github.com。 建议给 token 设有效期，别用勾了全部仓库的经典 token。
