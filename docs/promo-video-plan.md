# WordDrill 宣传短视频策划与制作方案（Remotion + Three.js · 25.4 秒 4K 60fps 双画幅）

## 1. 视频节奏、防重叠与 3D 透视标准

- **节奏曲线（快开头 → 稳中段 → 净落版，总长 25.4s / 1524 帧 @ 60fps）**：
  - 开场 2.8 秒干脆破题明身份；
  - 中间 3 幕核心学习能力（独立回想 5.4s、FSRS-6 跨日升阶与拼写 5.7s、按难度挑新词与自定义节奏 5.7s）留足观感与阅读呼吸；
  - 开放词库共建 4.4s + 品牌落版 3.4s。
- **数学级零文字重叠（接力式退场 / 进场）**：
  - 开场两段标语严格先后交替（Beat 1 在第 64 帧完全归零后，Beat 2 于第 68 帧登场）；
  - 幕间 24 帧过渡采用「前 11 帧柔顺退场归零 → 后 11 帧弹性进场」接力时序，杜绝转场双字叠影。
- **长焦电影镜头 3D 透视（Telephoto `fov=30° / 34°`）**：
  - 消除广角边缘畸变；FSRS-6 3D 曲线与光环改为严格共面（`z = 0`）建筑雕塑式呈现；移除穿插画面的斜向大环，保留远景景深光斑。
